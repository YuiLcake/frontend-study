第 17 天：伪类与伪元素

一个冒号和两个冒号的区别，决定了你是在"选中某个状态"还是"凭空造一个元素"。

一、伪类 vs 伪元素

伪类（一个冒号） 伪元素（两个冒号）
作用 选中元素的某种状态 凭空造一个不存在的元素
例子 :hover :focus :first-child :nth-child(2) ::before ::after ::selection ::placeholder
类比 "鼠标按在上面时的那个按钮" "这个按钮前面多出一个小圆点"
DOM 里有没有 本来就有，只是状态不同 本来没有，样式生成的

写法上：伪类 1 个冒号，伪元素 2 个。浏览器对 :before（1 个冒号）也兼容， 但那是老写法，新代码一律用双冒号。

二、常用的伪类

写法 选中什么
:hover 鼠标移上去时
:active 按住不放时
:focus 获得焦点时（点击输入框、用 Tab 移动到链接）
:focus-visible 只有键盘操作获得焦点时才生效
:first-child / :last-child 父元素里的第一个 / 最后一个子元素
:nth-child(2n) 第偶数个（2n = 2,4,6…；odd/even 是简写）
:not(.active) 排除某类
:disabled 被禁用的表单控件

:focus-visible 比 :focus 好用的原因

三、伪元素：凭空造一个元素

::before 和 ::after 会在元素内容的前面 / 后面插入一个 不在 HTML 里的盒子。必须写 content 属性，哪怕是空字符串。 

.box::before {
  content: "";          /* 没有这一行，整个伪元素不显示 */
  width: 8px;
  height: 8px;
  background: red;
}
最常见的错：忘了 content。
伪元素的默认 content 是 none，等于这个元素不存在。 写了 width、background 全部无效，页面上什么都没有，也不报错。

装饰圆点：

  • 不用在 HTML 里多加 span
  • 不改变文本内容（复制时不会带走圆点）
  • 换颜色只改一处
.dot-list li { position: relative; padding-left: 18px; }
.dot-list li::before {
  content: "";
  position: absolute; left: 0; top: 0.65em;
  width: 7px; height: 7px; border-radius: 50%;
  background: var(--c-accent);
}

四、招牌效果：下划线滑入

鼠标移到下面的链接上

这就是滑入的下划线 
.u-link {
  position: relative;
  text-decoration: none;
}
.u-link::after {
  content: "";
  position: absolute; left: 0; bottom: 0;
  width: 100%; height: 2px;
  background: currentColor;
  transform: scaleX(0);          /* 先压扁成 0 宽 */
  transform-origin: right;       /* 从右边开始收起 */
  transition: transform 0.25s ease;
}
.u-link:hover::after {
  transform: scaleX(1);          /* 展开到完整宽度 */
  transform-origin: left;        /* 从左边开始展开 */
}

三个要点：

  1. transform: scaleX(0) 而不是改 width——省一次重排
  2. transform-origin 决定"从哪一头长出来"。悬停时设 left（从左展开），离开时设 right（往右收回），所以两条规则各写一次
  3. background: currentColor 让下划线跟着文字颜色走

用伪元素做这个的好处：HTML 里只有标题和副标题，没有多余的图标标签。 装饰性内容进 CSS，语义内容才进 HTML。

六、两个小细节

选区颜色

用鼠标选中这句话，颜色会变成定制的高亮色。

::selection { background: #ffd7a8; color: #5c3b00; }

placeholder 的颜色

input::placeholder { color: #9198a1; }

::placeholder 只能改部分属性（颜色、字号可以，布局不行）， 因为它是浏览器原生绘制的占位提示。

七、三条纪律

  1. 伪元素不放真实内容。 ::before 里的文字不会被屏幕阅读器朗读，也无法被选中复制。 图标、装饰、符号可以；"报名"这种有意义的信息必须写在 HTML 里。
  2. 伪元素需要 position: relative 的父级。 因为 ::before / ::after 常配 position: absolute， 而绝对定位找的是最近的定位祖先。
  3. 同一个元素只有一对 ::before / ::after。 需要第三个装饰时，得在 HTML 里加元素，或者换个思路。
