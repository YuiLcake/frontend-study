伪元素到底是怎么工作的

一、它们不在 DOM 里

下面这一块，红字和蓝字都是 CSS 生成的：

我是 .demo-a 的正文
.demo-a::before { content: "[before]"; color: #d1242f; }
.demo-a::after  { content: "[after]";  color: #0963da; }

打开 DevTools 看这个元素，会看到 ::before 和 ::after 两个子节点。 但在 JS 里查不到它们——页面右下角有实测结果。

二、它们的位置是固定的

::before 永远是宿主元素的第一个子元素， ::after 永远是最后一个子元素。

所以上面那块的实际渲染顺序是：
::before → 正文「我是 .demo-a 的正文」→ ::after

名字容易误导：::after 不是"之后"，是"内容之后"。它仍然在宿主元素的内部。

三、默认是 inline，所以宽高无效

下面写了 40×40，但你看不到——因为默认 display: inline：

我前面应该有个 40×40 的红方块（看不到）

四、三种让它显出宽高的办法

办法 1：display: inline-block

我前面有个 40×40 的绿方块

办法 2：position: absolute（你页面里两个例子用的就是这个）

左边有个紫色圆点，绝对定位到左侧
.demo-d { position: relative; }        /* 宿主当参照物 */
.demo-d::before {
  content: "";
  position: absolute;                   /* 自动变成块级，宽高生效 */
  left: 10px; top: 50%;
}

办法 3：给宿主设 flex / grid，伪元素会变成项目，同样接受宽高。

六、放进 DevTools 里看

选中页面上任何一个伪元素，Computed 面板里能看到它的完整样式，就像普通元素一样。

这一步很值：伪元素出问题时，先看它在 Computed 里的 content 是不是 none， 再看 display 是 inline 还是别的。
