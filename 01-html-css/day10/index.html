第 10 天：Flexbox 下——六个固定套路

今天不学新属性，只学"组合技"。这六种模式覆盖了日常布局的绝大部分。

一、为什么要背套路

昨天的属性你已经会了：display: flex、justify-content、 align-items、gap、flex。

但真实工作里，你不是从零想"该用什么属性"，而是想"我要做一个三栏布局"—— 然后直接写出那几行。把常见需求背成固定组合，是布局提速的关键。

今天这六个，覆盖了你以后 80% 的布局需求。

二、套路 1：水平垂直居中

以前这是个著名的难题，现在三行搞定：

.parent {
  display: flex;
  justify-content: center;   /* 主轴（水平）居中 */
  align-items: center;       /* 交叉轴（垂直）居中 */
}
演示：容器 160px 高，里面的方块在正中间
我居中了

两个方向都要写。只写 justify-content 是水平居中，只写 align-items 是垂直居中。 这就是昨天说的"两个属性各管一条轴"最典型的应用。

三、套路 2：三栏布局（左右固定，中间自适应）

.layout { display: flex; gap: 12px; }

.left  { flex: 0 0 160px; }   /* 不长不缩，固定 160px */
.mid   { flex: 1; }           /* 吃掉全部剩余空间 */
.right { flex: 0 0 120px; }
演示：左右固定宽度，中间跟着窗口伸缩

中间自适应

flex: 0 0 160px 的三个值分别是 grow=0（不放大）、shrink=0（不缩小）、 basis=160px（基准宽度）。写 flex: 1 等价于 flex: 1 1 0%—— 能放大、能缩小、基准为 0，所以它总是吃掉剩余空间。

四、套路 3：等高列

三张卡片内容长短不一，想让它们高度一致——Flex 默认就会做到，不需要额外代码。

原理就是昨天讲的 align-items: stretch（默认值）——交叉轴方向拉伸对齐。 这曾经也需要 hack，现在是免费的。

五、套路 4：媒体对象（头像 + 文字）

评论区、消息列表、成员列表，全是这个结构：

.media { display: flex; gap: 12px; align-items: flex-start; }
.avatar { flex: none; }        /* 头像固定，不被压缩 */
演示

熙熙 · 3 分钟前

今天学了 Flexbox 的六个套路，其中媒体对象最实用。

关键是给头像写 flex: none——否则文字一长，头像会被压缩变形。 这是这个模式里唯一容易错的地方。

六、套路 5：卡片网格（自动换行）

.grid { display: flex; flex-wrap: wrap; gap: 16px; }
.grid > * { flex: 1 1 220px; }
演示：窗口宽时三列、窄时两列、更窄时一列

第四张卡片的宽度：空间够时它跟前面几个平分，不够时它单独换行并占满整行。 这就是 flex: 1 1 220px 的效果——最小 220，能长能缩。

七、套路 6：页脚贴底（sticky footer）

内容很少的页面，页脚会浮在页面中间。想让它永远贴底：

body {
  min-height: 100vh;      /* 至少占满一屏 */
  display: flex;
  flex-direction: column;
}
main {
  flex: 1;                /* 主内容吃掉多余空间，把页脚推下去 */
}

min-height 而不是 height：内容超过一屏时页面要能继续长。 用 height 会把内容裁掉。

八、作业

  1. 侧栏 + 主内容变成两栏：你的 main 里现在是 section.posts 和 aside.sidebar 上下排列。 改成左右： 
    main {
  display: flex;
  flex-wrap: wrap;
  gap: 24px;
  align-items: flex-start;
}
.posts   { flex: 1 1 420px; }
.sidebar { flex: 0 1 240px; }

    窄屏时会自动变成上下（因为 wrap + 两个 basis 加起来放不下）。 这就是内在响应式，不需要媒体查询。

  2. 页脚贴底：给 body 加 min-height: 100vh; display: flex; flex-direction: column;， 给 main 加 flex: 1;。 然后打开内容很短的 contact 页——页脚应该贴在窗口底部，而不是浮在中间。
  3. 卡片里的图片改成媒体对象：给 .post img（如果有）或侧栏那个 figure 加 display: flex; gap: 12px; align-items: center;， 图片设 flex: none，让文字和图片横排。
  4. 检查等高：把两栏布局做出来后，看两根栏的高度是否一致。 如果侧栏被拉得跟主内容一样高，那就是 align-items: stretch 在起作用； 如果你希望它只占自己需要的高度，就写 align-items: flex-start （上面的代码已经写了）。两种都试试，记住区别。

九、深水区（约 1 小时）

任务：复刻一张 GitHub 仓库卡片。

打开 https://github.com/YuiLcake/frontend-study ， 看右侧或列表里的仓库信息卡（有仓库名、描述、语言圆点、star / fork 数）。

要复刻的要素：

  • 第一行：仓库名（蓝色、加粗）+ 一个"Public"标签
  • 第二行：一行描述文字
  • 第三行：左侧一个彩色圆点 + 语言名，中间 star 数，右边 fork 数
  • 整张卡片有边框、圆角、内边距
  • 鼠标移上去有淡淡的背景变化

技术约束：只能用 Flexbox。第三行那种"左边一组、右边一组"的排布， 正是 justify-content: space-between + 内部嵌套 flex 的练习。

自检：1440px 宽度下和 GitHub 原卡并排，看三行的位置关系是否一致。 不用管字体和精确颜色。

这张卡片几乎用到了今天全部的套路：媒体对象（圆点 + 文字）、 space-between（左右分组）、嵌套 flex、gap、align-items。 能独立做出来，W2 的 CSS 就算过关了。
