第 12 天：CSS 变量与设计令牌

今天学一个"用一次就回不去"的东西。它会一直用到你的毕设。

一、没有变量的时候有多痛

看看你现在站点的 CSS：

.post h3 { color: rgb(190, 3, 190); }
body      { color: #222; }
.repo-name { color: #4493f8; }
...

假设你要把全站的紫色换成蓝色。你得打开文件、搜索、一处一处改。 改漏一处，就有一个地方颜色不对，而且你可能永远注意不到。

这还只是颜色。字号、间距、圆角全都散落在各处，更没法统一调整。

二、CSS 变量是什么

官名叫 自定义属性（custom properties），写法是以两个减号开头： 

/* 声明：定义一个叫 --c-accent 的变量，值是蓝色 */
:root {
  --c-accent: #0969da;
}

/* 使用：用 var() 取出来 */
.btn {
  background: var(--c-accent);
}

:root 是文档的根元素（就是 <html>）。 定义在这里，全页面都能用。

把它想成一个"全局配置表"：颜色、间距、字号都写成变量放在最上面， 下面所有规则都来取。以后改配色，只改表里那一行。

这两个按钮取的都是 var(--c-accent)：

现在给外面套一个类，只改一个变量的值：

.theme-purple { --c-accent: #8250df; }   /* 一行 */

两个按钮的颜色、边框、文字色一起变了——因为它们全都引用同一个变量。 这就是变量的全部价值：一处定义，处处引用，改一处全变。

三、作用域：变量是"往下传"的

变量不是全局唯一的。定义在哪个元素上，就只对它自己和它的后代生效。 这就是"层叠"在变量上的体现。 

:root        { --c-accent: #0969da; }   /* 全站蓝 */
.scope-box   { --c-accent: #1a7f37; }   /* 这一块改绿 */
这一块里的 --c-accent 被改成了绿色——边框和按钮都跟着变。

块外面的东西不受影响，还是蓝色。 这条规则的用处极大：想给某一块区域换个主题，只要在那个容器上重新定义变量， 里面所有子元素自动跟着变，不用逐个写类名。

四、真正的用处：深浅主题

这是 CSS 变量最经典的场景。同一套结构，只换变量值，就变成两套皮肤。 

.card {
  background: var(--c-card-bg);
  color: var(--c-card-text);
  border: 1px solid var(--c-card-border);
}

/* 深色模式：只覆盖变量的值 */
.card[data-theme="dark"] {
  --c-card-bg: #0d1117;
  --c-card-text: #f0f6fc;
  --c-card-border: rgba(61, 68, 77, 0.7);
  --c-card-accent: #4493f8;
}

注意这些值眼熟吗？
#0d1117、#f0f6fc、#4493f8、 rgba(61, 68, 77, 0.7) —— 全部是你在复刻挑战里从 GitHub 量出来的。
你现在做的这张卡，装上变量之后，加一行属性就能切换深浅模式。

五、两个必须知道的细节

1. 变量名区分大小写

--Color 和 --color 是两个不同的变量。 约定俗成都用小写加连字符：--color-text、--space-4。

2. 可以给回退值

color: var(--c-accent, #0969da);
/* 变量没定义时用后面的兜底值 */

做主题系统时很有用：万一某个主题忘了定义某个变量，页面不会变成透明或黑色， 而是退回默认值。

六、设计令牌：一套变量就是一套设计系统

把变量按用途分类命名，而不是按颜色命名。对比一下：

❌ 按样子命名 ✅ 按用途命名
--blue、--light-gray、--purple --color-accent、--color-border、--color-text-muted
换成绿色主题时，"blue 变成了绿色"，名字骗人 不管什么主题，accent 永远是"强调色"，意思不变

一套最小可用的令牌表：

:root {
  /* 颜色 */
  --color-bg: #ffffff;
  --color-surface: #f6f8fa;
  --color-text: #1f2328;
  --color-text-muted: #59636e;
  --color-border: #d1d9e0;
  --color-accent: #0969da;

  /* 间距：4 的倍数 */
  --space-1: 4px;
  --space-2: 8px;
  --space-3: 12px;
  --space-4: 16px;
  --space-5: 24px;

  /* 圆角 */
  --radius-sm: 4px;
  --radius-md: 8px;

  /* 字号 */
  --text-sm: 13px;
  --text-base: 15px;
  --text-lg: 20px;
}

注意间距那五个：全是 4 的倍数。这就是你在复刻挑战里量到的"间距规律"。 把规律写成变量，就再也不用记数字了。

七、作业

在你的学习站点上做，改 docs/css/main.css 和 docs/index.html。

  1. 定义令牌表：在 main.css 最上面加 :root { ... }， 至少包含 6 个颜色、4 个间距、2 个圆角、3 个字号。 值就用你现在站点正在用的颜色，不要改外观。
  2. 替换硬编码：把文件里所有写死的颜色、间距、圆角换成 var()。 改完刷新，页面必须和改之前长得一模一样——这是验收标准。
  3. 做一套深色主题：给 <body> 加 data-theme="dark" 属性选择器，在里面覆盖颜色变量。然后手动给 body 加上这个属性，看整站变深色。
  4. 回答（写在 CSS 注释里）：如果把 :root 里的 --color-accent 改成红色，页面里哪些地方会变？
第 2 步是重点。替换过程会让你发现：有些地方你根本不知道用了什么颜色 （因为当初是随手写的），有些间距根本不是 4 的倍数。 这个过程本身就是在整理你的设计系统。
