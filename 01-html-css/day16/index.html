第 16 天：过渡与变形

把鼠标放上去试每一个演示。CSS 动效的全部秘密就两条：transition 和 transform。

一、为什么需要过渡

下面两个方块，鼠标移上去看看区别。

瞬间变
平滑变

左边那个是"跳"过去的，右边是"滑"过去的。区别只有一行：

.smooth {
  transition: background-color 0.3s ease, color 0.3s ease;
}

人眼对"突变"的感知是很差的——尤其是小而频繁的交互（悬停、点击）。 过渡不改变功能，只改变感受。但它决定了一个页面"精致"还是"廉价"。

二、transition 的四个值

transition: 属性 时长 缓动 延迟;

/* 例子 */
transition: transform 0.3s ease 0s;

/* 多个属性用逗号分开 */
transition: transform 0.25s ease, box-shadow 0.25s ease;

/* 或者偷懒全都要（不推荐，会连你没想动的属性一起过渡） */
transition: all 0.3s ease;
值 作用 常用
属性 要过渡哪个属性 transform、background-color、opacity
时长 走完这个过程要多久 悬停 0.2s，大的位移 0.4s
缓动 速度曲线 ease（默认）、ease-out、cubic-bezier()
延迟 等多久再开始 大部分情况 0s
最常见的坑：transition 写在了 :hover 里面。
.btn:hover { transition: ... } 只在你移进去时生效，移出来是瞬间跳回。
正确做法是写在基础状态上——两边都平滑。

缓动曲线有什么不同

鼠标移到圆点上，看它们跑的方式

linear
ease
ease-in-out
bounce

linear 匀速，机械感强；ease 两头慢中间快，最自然； 最后那个用了 cubic-bezier(0.34, 1.56, 0.64, 1)，超过 1 的控制点会产生"弹一下"的效果。

三、哪些属性可以过渡

能过渡 不能
有中间值的：颜色、长度、透明度、transform、box-shadow 没有中间值的：display、visibility（其实可以但很生硬）、height: auto

display: none → block 没法过渡，因为"不存在"和"存在"之间没有中间状态。 要做展开收起，得用 max-height、grid-template-rows: 0fr → 1fr 或 JS 量高度。

四、transform：四种变换

transform: translate(20px, -10px);   /* 位移：左右、上下 */
transform: scale(1.2);                /* 缩放：1 是原始大小 */
transform: rotate(45deg);             /* 旋转 */
transform: skew(10deg);               /* 倾斜（很少用） */

/* 可以连写，空格隔开，从右往左依次作用 */
transform: translateY(-6px) scale(1.05);

rotate 默认绕中心转。想绕别的点转，用 transform-origin: top left; —— 下拉箭头、展开动画常用这个。

五、为什么动画要用 transform，而不是 top / left

想让元素"上移 6px"，有两种写法：

/* 写法 A */
.box { position: relative; top: 0; transition: top 0.25s; }
.box:hover { top: -6px; }

/* 写法 B */
.box { transition: transform 0.25s; }
.box:hover { transform: translateY(-6px); }

两种看起来一样，但底层完全不同：

改 top 改 transform
影响布局 会。浏览器要重新算周围元素的位置 不会。只影响自己怎么"画"
性能 涉及重排（reflow），容易掉帧 走合成层，通常由显卡处理
周围元素 会跟着动 纹丝不动
一句话记住：transform 是"画的位置变了"，不是"占的位置变了"。
所以它不触发重排，是动画的首选。同理，能用 opacity 就别用 visibility + display。

六、三个最常用的组合

1. 卡片浮起

.card {
  transition: transform 0.25s ease, box-shadow 0.25s ease, border-color 0.25s ease;
}
.card:hover {
  transform: translateY(-6px);
  box-shadow: 0 8px 24px rgba(31, 35, 40, 0.12);
  border-color: #a8c7fa;
}

三个属性一起过渡，才有"浮起来"的感觉。只位移会显得轻飘，只加阴影会显得突兀。

2. 按钮按下去

点我试试 
.btn { transition: transform 0.12s ease, background-color 0.2s ease; }
.btn:hover  { background: #0550ae; }
.btn:active { transform: scale(0.96); }   /* 按下的瞬间缩小一点点 */

:active 是"按住不放"的状态。0.12s 要快——慢了会觉得按钮"粘手"。

3. 时长参考表

场景 建议时长
按钮、链接反馈 0.1 – 0.2s
卡片、菜单悬停 0.2 – 0.3s
弹窗、抽屉打开 0.3 – 0.4s
页面级转场 0.4 – 0.6s

超过 0.5s 的微交互会让人觉得卡。动画是调味料，不是主菜。

七、必须加的一段：尊重"减少动效"

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    transition: none !important;
    animation: none !important;
  }
}

有些人对动效敏感——前庭功能障碍的人会因为页面元素移动而眩晕、恶心。 系统层面开了"减少动态效果"后，这个媒体查询就会命中。

这不是"加分项"，是基本素养。而且它只影响那些主动开了这个开关的用户，对其他人零影响。
