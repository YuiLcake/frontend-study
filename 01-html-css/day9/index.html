第 9 天：Flexbox 上——主轴、交叉轴、对齐

这一节是整周最重要的。学完它，你才真正开始"布局"。

一、为什么需要 Flexbox

你之前想让三个盒子并排，用的是 inline-block 或者 float。 这两种办法都能排，但有一堆麻烦：元素之间的空白间隙、垂直居中做不出来、 高度不一致会错位、还要手动清除浮动。

Flexbox 把这些事一次解决：你只声明"我要横着排、怎么对齐、间距多少"， 剩下的浏览器算。

一句话记法：Flexbox 是给"一维"布局用的——要么排成一行，要么排成一列。 二维（行和列同时控制）用 Grid，下周学。

二、容器和项目，主轴和交叉轴

用 Flex 有两个角色：

  • 容器：写了 display: flex 的那个元素
  • 项目：容器直接子元素（不是孙子，只认直接子元素）

容器里有两条轴：

轴 方向 由谁决定 控制对齐的属性
主轴（main axis） 默认水平，从左到右 flex-direction justify-content
交叉轴（cross axis） 与主轴垂直 跟着主轴走 align-items

这是初学者最容易乱的一点：justify-content 管的是"沿着主轴怎么排"， align-items 管的是"沿着交叉轴怎么对齐"。主轴是横的时候，前者管左右、后者管上下； 一旦把 flex-direction 改成 column，主轴变成竖的，两个属性的职责就对调了。

五、gap：项目之间的间距

不用再给子元素一个个加 margin，直接在容器上写 gap：

1
2
3
.container {
  display: flex;
  gap: 16px;          /* 项目之间 16px，两端不加 */
  gap: 16px 24px;     /* 行间距 16，列间距 24 */
}

gap 只加在项目之间，不会加在两端——所以它比 margin 好用， 不会像 margin 那样在边缘多出空白。

六、flex：让项目自己分配剩余空间

flex 是三个属性的简写：flex-grow（能长多大）、 flex-shrink（能缩多小）、flex-basis（初始占多少）。 实际项目里 99% 的情况只写前两个值或者一个值：

写法 含义 用在哪
flex: 1 剩余空间全给我，几个各 1 就平分 等宽分栏、占满剩余
flex: 2 我拿两份，别人一份 主内容区宽、侧栏窄
flex: 0 0 200px 不长不缩，固定 200px 固定宽度的侧栏、图标位
flex: none 完全按自身内容大小 按钮、标签

column：主轴变成竖直，justify-content 就变成管上下

2

记住这条：justify-content 永远管主轴，align-items 永远管交叉轴。 轴转了，它们管的方向就跟着转——不要死记"左右"和"上下"。

八、flex-wrap：装不下时换行

默认 nowrap：所有项目挤在一行，宁可压缩也不换行。 改成 wrap 之后装不下就换到下一行——做响应式卡片列表必须开。 

.cards {
  display: flex;
  flex-wrap: wrap;
  gap: 20px;
}
.card {
  flex: 1 1 260px;   /* 最小 260px，空间够就长，不够就换行 */
}

九、作业

  1. 导航改成 flex：现在是 inline-block 拼出来的。 在 main.css 里把 nav 改成 display: flex; gap: 8px; align-items: center;， 然后把 nav a 的 display: inline-block 删掉。 视觉应该几乎不变，但结构更正确了。
  2. 卡片头部改成 flex 分布：现在是给 .post time 用了 absolute。 改成用 Flex 实现同样的效果： 
    .post header {
  display: flex;
  justify-content: space-between;
  align-items: baseline;
}
    然后把 .post time 里的 position: absolute; top: 14px; right: 20px; 三行删掉。 对比一下：哪种写法你更愿意维护？（答案是后者，因为它不依赖"父元素必须定位"这个隐藏条件）
  3. footer 改成两端分布：现在版权和邮箱挤在一起。给 footer 加上 justify-content: space-between;，让版权靠左、邮箱靠右。
  4. 日志列表改成并排卡片：给 .posts 加 display: flex; flex-wrap: wrap; gap: 20px;， 给 .post 加 flex: 1 1 260px;， 并把它的 margin-bottom 删掉（间距交给 gap）。 窗口拉宽时卡片应该自动变成两列、三列。

十、深水区（新增，约 1 小时）

这一段不加新知识，只做一件事：把真实网站的导航栏复刻出来。

任务：打开 https://developer.mozilla.org/zh-CN/ ，只看顶部那条导航栏，复刻它。

要求：

  • 左边是 logo（可以先用一个色块 + 文字代替）
  • 中间或右边是一排文字链接，间距均匀
  • 最右边有一个按钮（比如"登录"或"主题切换"）
  • 整条栏高度固定，内容垂直居中
  • 窗口拉窄到 400px 时，链接可以换行或者隐藏——你自己选一种合理的处理

要用的：只有今天学的 display: flex、justify-content、 align-items、gap、flex: 1。不准用 float，不准用 absolute。

自检标准：把你的版本和原网站并排放，宽度 1440px 下看——位置、间距、 对齐方式是否一致。不用管颜色和字体，只看布局骨架。

为什么用 MDN 而不是随便是哪个网站：MDN 的导航栏结构干净、左边 logo + 中间菜单 + 右边按钮，是全世界最常见的导航布局。复刻完这一个，你以后遇到 80% 的网站导航都能套。
