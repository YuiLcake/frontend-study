第 13 天：Grid 布局基础

昨天之前你只有一个布局工具。今天多第二个——而且它管的是 Flex 管不了的事。

一、Flex 的边界在哪

Flexbox 是一维布局：它一次只处理一个方向。你要么排一行，要么排一列。

所以做卡片列表时，你得靠 flex-wrap: wrap 让它自己换行—— 但你控制不了"每行几个"。它是根据宽度自己算的。

如果你想要"左边一块固定、右边一块自适应、而且右边内部再分两行"这种**同时管行和列**的布局， Flex 就得靠一层层嵌套硬凑。

Grid 是二维的：你先画好一张格子纸，然后把元素放进去。

怎么选，一句话：
整体页面骨架（几行几列）用 Grid；组件内部的排列（一行按钮、一个头像加文字）用 Flex。
不是"哪个更高级"，是"哪个更顺手"。很多人习惯全用 Flex，也能做出来，只是更啰嗦。

二、最小可用：三列

.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);   /* 三列，每列一份 */

三、fr 是 Grid 的灵魂

fr 是"份"（fraction）。它表示剩余空间按比例分，不是固定像素。 

grid-template-columns: 1fr 2fr 1fr;   /* 中间是两边两倍宽 */

五、命名区域：把布局画出来

这是 Grid 最好用的功能。直接在 CSS 里画一张图，每个词代表一块区域： 

.layout {
  display: grid;
  grid-template-columns: 140px 1fr;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "head head"
    "side main"
    "foot foot";
  gap: 8px;
}

.area-head { grid-area: head; }
.area-side { grid-area: side; }
.area-main { grid-area: main; }
.area-foot { grid-area: foot; }
效果：这块就是整个页面骨架

侧栏
主内容
footer（横跨两列）

那张用引号写的图，形状就是布局本身。同一个词出现几次，那块区域就跨几格。 改布局只要改这张图，不用碰 HTML。

为什么这个重要：手机版和桌面版可以用同一套 HTML， 只换两张 grid-template-areas 图。
桌面版是侧栏在左，手机版可以写成 "head" "main" "side" "foot" 一列到底——改三行字符串就完成适配。

这句话拆开读：

部分意思
repeat(auto-fit, ...)能塞几列就塞几列，数量我自己算
minmax(180px, 1fr)每列最窄 180px，最宽可以到 1fr（平分剩余）

容器够宽 → 塞更多列；容器变窄 → 列数减少，直到只剩一列。 全程没有写一行媒体查询。这和你之前学的 flex-wrap 是同一类"内在响应式"， 但 Grid 版能控制"每列最小多宽"。

七、对齐：三个层级的区别

Grid 里的对齐分两层：整个网格在容器里怎么摆，和格子里的内容怎么摆。

属性管什么
justify-content整个网格在容器里水平怎么摆（网格比容器小的时候才有意义）
align-content整个网格垂直怎么摆
justify-items每个格子里的内容水平怎么对齐
align-items每个格子里的内容垂直怎么对齐
place-items上面两条的简写：place-items: center
place-items: center —— 每个格子里的内容都居中

注意这些名字和 Flex 是同一套（items / content / justify / align）， 但含义有差别：Flex 里 justify-content 管主轴（可能是横也可能是竖）， Grid 里 justify 永远管横、align 永远管竖。
