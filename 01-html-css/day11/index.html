W2 Day11 · 复刻挑战

2-3 小时，复刻真实网站的一块。这是 W2 的收官，也是第一次完整模拟真实工作。

一、先学方法：怎么读别人的页面

新手复刻的方式通常是"看着像，凭感觉写，然后无限微调"。 专业做法是反过来：先量，再写。

四步测量法

  1. 看结构：右键 → 检查，把目标区域的 HTML 展开。 数清楚几层、谁包谁、哪些是并列的兄弟。 这一步不要写代码，只在纸上/脑子里画出层级。
  2. 量盒子：选中每一层，看 Styles 面板最下方的盒模型图。 记下 padding、border、margin 的数值。
  3. 读文字样式：在 Computed 面板看 font-size、line-height、color、font-weight。 颜色可以直接复制十六进制值。
  4. 量间距规律：把几个间距值写下来，看它们是不是同一套倍数 （常见是 4 / 8 / 12 / 16 / 24）。 看出一套系统，比记住一堆数字有用。
禁止：直接抄他们的 CSS。 你可以看数值，但选择器、结构、写法必须自己写。 抄一遍什么也学不到；量一遍再自己实现，才是真的会。

二、选题（选一个）

选题 A：GitHub 仓库卡片（推荐，约 2 小时）

目标页面：https://github.com/YuiLcake?tab=repositories 上的仓库列表卡。

卡片里的四层内容：

  • 第一行：仓库名（蓝色、粗体）+ 紧跟其后的 "Public" 小标签（灰色描边）
  • 第二行：一句描述，灰色
  • 第三行：彩色圆点 + 语言名、星标数、分支数（图标可以用文字符号代替：★ ⑂）
  • 整卡：1px 边框、圆角、内边距、鼠标悬停时边框变蓝

难点在于第一行：仓库名和标签要"挨着"，不是两端分开。 这里要用 flex + gap，而不是 space-between——先想清楚这两个的区别再动手。

选题 B：定价表（更难，约 3 小时）

找任意一个有定价页的网站（Vercel、Linear、Notion 都行），复刻三张价格卡并排：

  • 三张卡等高（flex 默认就能做到）
  • 中间那张"推荐"的稍微突出（边框加粗或加个标签）
  • 每张卡：名称、价格、功能清单、底部按钮
  • 按钮要在卡片最底部对齐——即使某张卡的功能条目更多

难点是最后一条：按钮对齐。这需要把卡片本身做成 flex 列，再给按钮上面的内容 flex: 1，把按钮顶到底部。这是"卡片内部也用 flex"的典型场景。

三、验收标准

维度合格线
结构语义标签，不用 table 布局，不用 absolute 排位置
布局用 flex 完成；能用 gap 就不用 margin 造间距
间距用同一套数字（4 / 8 / 12 / 16 / 24），不是随手取的值
响应式窗口拉到 400px 不出现横向滚动条，内容不重叠
还原度1440px 宽度下与原站并排，各元素的位置关系一致（颜色和字体不必完全一致）

交付方式

文件放 practice2/challenge.html（或自己起个名字）， 样式可以写在文件内的 <style> 里——这次是单文件挑战，不用拆。

时间盒

2-3 小时到就停。做不完的部分记下来——没做完的原因比做完的结果更有信息量： 是卡在结构？卡在某个属性？还是卡在"看着像但不知道差在哪"？

四、做的时候注意

  • 先搭结构，再写样式。HTML 写完在浏览器里看，是一堆竖着排的方块——这是对的。
  • 一次只调一个东西。改一个值，刷新，看效果。不要同时改五个然后不知道是哪个起的作用。
  • 卡住超过 30 分钟就问我。今天允许问的次数不限，但要先描述清楚你试过什么、现象是什么。
  • 做完自己先对照检查一遍，把"我做到哪、哪里没做到"写进文件末尾的注释。
