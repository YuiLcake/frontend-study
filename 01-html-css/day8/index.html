第 8 天：display 与 position

昨天学的是"一个盒子内部怎么算"，今天学的是"盒子之间怎么摆"。

一、先理解"文档流"

默认情况下，浏览器从上到下、从左到右依次排列元素，这个默认秩序叫文档流。 你写的所有 HTML，本来都在这个流里排着队。

今天要学的两个属性，干的都是同一件事：改变元素在流里的行为。 display 改变它"怎么占位置"，position 改变它"还在不在流里"。

二、display：这个元素怎么占位置

值行为宽度高度典型元素
block独占一行，前后强制换行可以设div、p、h1、section
inline跟文字排在同一行，不换行不能设（设了也没用）span、a、strong
inline-block像 inline 一样排在一行，但能设宽高可以设img、button
flex变成"弹性容器"，子元素按规则排列可以设现代布局的主力，下周讲
none完全不渲染，也不占位置—隐藏元素

看演示：三种都设了 width:200px; height:40px

block：独占一行，宽高生效
block：第二行
inline：宽高不生效 inline：还在同一行
inline-block：能排一行
inline-block：也能设宽高

蓝色那两个 span 写了 width:200px 和 height:40px，但你看它们还是文字大小—— 行内元素的宽高属性直接被忽略。绿色的 inline-block 才真的撑成了 200×40 的方块。

display: none 和 visibility: hidden 的区别

写法还占位置吗什么时候用
display: none不占，后面的元素会顶上来真的要从页面上拿掉
visibility: hidden占，留着一个空白保留布局，只是看不见

三、position：这个元素还在不在流里

值相对谁偏移还占原来的位置吗
static（默认）不偏移占
relative相对自己原来的位置占（会留一个空位）
absolute相对最近的已定位祖先（position 不是 static 的祖先）不占，完全脱离文档流
fixed相对浏览器视口不占，滚动时不动
sticky先按正常流走，滚到阈值后吸附先占，吸附时脱离

看演示

static：正常排队
relative：往右下挪了 12px / 24px，但原来的空位还在
absolute：贴在容器右上角，不占流里的位置

注意那个粉色 relative 盒子：它挪动了，但它原来的位置仍然被占着—— 下面的元素没有顶上来。而右上角那个 absolute 盒子完全没影响其他元素。

absolute 的参照物最容易搞错。它找的是"最近的、position 不是 static 的祖先"。 如果一路往上都没有，它就相对整个页面（html）定位。 这就是为什么做绝对定位前，通常先给父元素加一句 position: relative ——不是为了移动父元素，是为了给子元素划一块"定位范围"。

四、z-index：谁在上面

元素重叠时，z-index 决定谁盖住谁，数值大的在上层。 但有三个前提，缺一不可：

  • 元素必须是定位元素（position 不是 static）
  • 同一个"堆叠上下文"内比较
  • 默认值是 auto，不写的话按 HTML 顺序，后面的盖前面的

"堆叠上下文"暂时不用深究。现在只要记住：给固定定位的悬浮按钮加 z-index: 10，能保证它盖在内容之上。

五、最常用的一个组合：父相子绝

这两个属性在真实项目里几乎总是配对出现：

/* 父：声明"我这里是定位范围" */
.card {
  position: relative;
}

/* 子：挂到这个范围的某个角上 */
.card .badge {
  position: absolute;
  top: 8px;
  right: 8px;
}

你见过的一切"右上角的小红点""图片左上角的新品标签""表单右上角的删除按钮"， 都是这个组合。

六、今天的作业

  1. 导航变成按钮：在 main.css 里改 nav a， 加 display: inline-block; 和 padding: 6px 12px;， 再加一条 nav a:hover { background: #eef4ff; border-radius: 4px; }。 原来的 | 分隔符可以删掉了。
  2. 给卡片建立定位范围：.post 里加上 position: relative;。这一步不会有任何视觉变化——它的作用是给下一步做准备。
  3. 把日期挪到卡片右上角：加一条规则 
    .post time {
  position: absolute;
  top: 14px;
  right: 20px;
  font-size: 13px;
  color: #999;
}
    刷新看：日期从标题下面跳到了卡片右上角，而且标题下面的空间被"收上去"了 ——因为 absolute 让 time 脱离了文档流。
  4. 加一个"回到顶部"按钮：在 docs/index.html 的 </body> 前加一行 
    <a class="to-top" href="#">↑ 顶部</a>
    然后在 main.css 里写： 
    .to-top {
  position: fixed;
  right: 24px;
  bottom: 24px;
  z-index: 10;
  padding: 10px 14px;
  background: #222;
  color: #fff;
  border-radius: 6px;
  text-decoration: none;
  font-size: 14px;
}
    刷新后滚动页面，按钮应该一直贴在右下角不动。
  5. 做个对比实验：在 DevTools 里给某张卡片临时加 display: none 看效果，再改成 visibility: hidden， 记录两者的差别（哪个让下面的内容顶上来了）。

这五条做完，你的站点会有第一个"悬浮元素"和第一个"角标"。 这两样东西是所有后台系统、电商页、内容站的标配。
