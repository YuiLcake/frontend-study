第 6 天：CSS 入门——先学会"指哪打哪"

前一周你在写"内容是什么"。从今天起，你决定"它长什么样"。

一、CSS 解决什么问题

HTML 只负责结构和语义，CSS 负责表现：颜色、字体、间距、位置、大小。 分开的好处是同一份内容可以有不同的样子（手机版、打印版、暗色模式）。

写 CSS 的两件事永远在循环：选中元素，给它声明样式。 选择器是前半句，声明是后半句。 

选择器 {
  属性: 值;
  属性: 值;
}

/* 例子：选中所有 h2，字号 24 像素，下边距 12 像素 */
h2 {
  font-size: 24px;
  margin-bottom: 12px;
}

二、CSS 怎么写进页面：三种方式

方式写法评价
外部样式表 <link rel="stylesheet" href="css/main.css"> 正确做法。一份样式管多个页面，改一处全部生效，浏览器还能缓存
内部样式表 <style> … </style> 写在 head 里 只在单个页面、或临时调试时用。三页各写一份就是灾难
行内样式 <p style="color: red"> 尽量不用。优先级最高、无法复用、以后改起来要一个个找

你现在三个页面各有一份完整的 <style>，三份内容几乎一样。 这就是"内部样式表"的问题——想改一个颜色要改三个地方，漏一个就不一致。 今天的作业就是把它合并成一个外部文件。

三、选择器：先说清选谁

选择器写法选中什么
类型p所有 p 元素
类.post所有 class="post" 的元素（最常用）
ID#postsid="posts" 的那一个元素（页面里唯一）
后代nav anav 里面任意层级的 a
子代nav > anav 的直接子元素 a
并集h1, h2h1 和 h2 都选
属性input[type="email"]type 等于 email 的 input
伪类a:hover鼠标悬停时的 a（状态）
伪元素p::first-line元素内部的某一部分（这里指第一行）
通用*所有元素（慎用，性能差）

记两种就够开始：p（元素）和 .post（类）。 类选择器是你以后 90% 时间在用的东西——它不绑定标签，随处可复用。

四、优先级：为什么我的样式没生效

这是新手第一个大坑。当多条规则选中同一个元素，浏览器要决定听谁的。 规则是算分，分高的赢：

来源分数例子
行内样式1000style="color:red"
ID 选择器100#posts
类 / 属性 / 伪类10.post、[type]、:hover
元素 / 伪元素1p、::before
!important最高压过一切（除非另一条也写了）

算个分：

nav a = 1 + 1 = 2 分

.post h3 = 10 + 1 = 11 分

article .post h3 = 1 + 10 + 1 = 12 分

所以第二条会赢第一条，第三条会赢第二条——不管它们谁写在前面。

!important 为什么是坏东西

它一写上就压过一切，只有另一条 !important 能盖它。于是为了盖住别人， 你只能再加 !important，最后整个项目的优先级变成一团乱麻。 真实项目里的规律是：只有在覆盖第三方库、别无办法时才用。

遇到"样式没生效"，正确的排查顺序是：DevTools 选中元素 → 看 Styles 面板 → 被划掉的那条就说明被更高优先级的规则盖住了，它下面会写着来自哪个文件哪一行。

五、层叠与继承

层叠：优先级相同的时候，后写的赢。 这条规则解释了为什么 CSS 里顺序有意义——同一个文件里，越靠后的规则越强势。

继承：有些属性会自动传给子元素，有些不会。

会继承不会继承
color、font-family、font-size、line-height、text-align margin、padding、border、width、height、background、display

所以你在 body 上写 color: #222，全站文字都变深灰——因为 color 会继承。 而在 body 上写 border，只有 body 自己有边框，子元素不会有。

六、今天的作业：把三份样式合并成一份

你的三个页面现在各有一份几乎相同的 <style>， 而且里面塞着大量用不到的规则（form、table、input……三个页面都没用到）。 今天把它们合并、清理、外置。

  1. 建文件：在 docs/ 下新建 css/ 文件夹， 里面建 main.css。
  2. 搬规则：把三个页面 <style> 里的规则搬进去， 但只保留真正用得到的：body、header、section、article、aside、footer、img。 表单、表格、textarea、fieldset、legend、caption、.hint、.field 全部删掉 ——这三个页面里没有那些元素，写了也不会生效。
  3. 改引入：三个页面都删掉整段 <style>， 在 <head> 里加： 
    <link rel="stylesheet" href="css/main.css">
    注意路径：三个页面和 css 文件夹是同级，所以写 css/main.css。
  4. 加三条新规则，练选择器：
    • nav a：左右各 4px 内边距，去掉下划线
    • nav a:hover：文字变成 #0066cc
    • .post h3：字号 20px，颜色 #1a1a1a
  5. 做个优先级实验（这条最重要）：在 main.css 里同时写下 
    article h3 { color: red; }
.post h3 { color: navy; }
    刷新页面，记下标题实际是什么颜色，然后用今天学的算分法解释 为什么（提示：一个是 1+1=2 分，一个是 10+1=11 分）。 把结论写在 main.css 最后的注释里，然后把红色那条删掉。

做完之后你会得到：一份样式文件、三个页面共享、想改颜色只改一处。 这就是"外部样式表"的实际价值——不是规范要求，是省事。
