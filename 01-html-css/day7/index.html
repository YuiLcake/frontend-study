第 7 天：盒模型——CSS 的地基

上周那个 box-sizing 的疑问，今天彻底讲清。

一、页面里每个元素都是一个盒子

不管它看起来多不像盒子，浏览器内部都把它当成一个矩形框来处理。 这个框由里到外有四层：

层中文作用DevTools 里的颜色
content内容区文字、图片真正占据的地方蓝色
padding内边距内容到边框的距离，会撑大盒子绿色
border边框盒子自己的边线黄色
margin外边距这个盒子与其他盒子的距离橙色

看这个盒子，四层用不同颜色标出来了（外层浅橙是 padding，里层蓝色是 content，黑色粗边是 border，上下留白是 margin）：

内容区 220px 宽

用 DevTools 选中它，右侧 Styles 面板最下面有一个盒模型图，四层颜色和你看到的一致， 数值也写在上面。这是你以后调间距时最常用的工具，比反复改代码快十倍。

二、box-sizing：那个让你疑惑 width: 100% 溢出的东西

先记住一句话：width 到底管哪一层，取决于 box-sizing。

值width 包含什么结果
content-box（默认） 只算内容区 width:100% 再加上 padding 和 border，一定超出容器
border-box 内容 + padding + border width:100% 就是 100%，padding 从里面让位

下面两个盒子都是 width:100%; padding:20px; border:6px solid，唯一区别是 box-sizing：

content-box：我溢出了虚线框
border-box：我规矩地待在框里

外面那条虚线框宽 320px。上面红边的盒子明显冲出去了——因为 320px 的内容 + 40px padding + 12px border = 372px。下面绿边的盒子没有，因为它把 padding 和 border 算在那 320px 里面。

上周你在 textarea 上踩过这个坑：width: 100% 顶到了 fieldset 的边框， 你当时的办法是把宽度改成 90% 来"凑"。那不是解决，是绕开。 真正的解法就是今天这个 box-sizing: border-box。

真实项目里的标准做法，几乎所有站点都会在 CSS 开头写这三行：

*,
*::before,
*::after {
  box-sizing: border-box;
}

为什么连伪元素一起写：因为 ::before / ::after 也是盒子，同样会受 box-sizing 影响。 统一成 border-box 之后，你写的 width 就是你想要的宽度，不用再心算 padding。

三、margin 折叠：两个 30 不会变成 60

这是 CSS 里最反直觉的规则之一：上下相邻的两个块，它们之间的 margin 会合并，取较大的那个， 而不是相加。

下面两个盒子的 margin-bottom 和 margin-top 都是 30px：

上面的盒子，margin-bottom: 30px
下面的盒子，margin-top: 30px

它们之间的间距是 30px，不是 60px。

只在垂直方向、相邻的块级元素之间发生。左右方向的 margin 不会折叠。 这条规则会解释你以后遇到的很多"为什么间距不对"。

规避办法：给父元素加 display: flex（Flex 布局里的子元素之间不折叠， 改用 gap 控制间距）——这就是下周要学的 Flexbox 更省心的原因之一。

四、简写和单位

四个值怎么省略

写法含义
margin: 10px;四边都是 10
margin: 10px 20px;上下 10，左右 20
margin: 10px 20px 30px;上 10，左右 20，下 30
margin: 10px 20px 30px 40px;上 10，右 20，下 30，左 40（顺时针）

居中为什么是 margin: 0 auto

auto 的意思是"把剩下的空间自动分配给左右两边"，两边一样多，盒子就居中了。 所以它要求这个盒子有明确的宽度，否则没有"剩下的空间"可分。

单位

单位相对谁什么时候用
px绝对像素边框、圆角、细小间距
%父元素的宽度流式布局，注意它永远是相对宽度
rem根元素 html 的字号（默认 16px）字号、间距，用户放大字号时会跟着变
em当前元素的字号组件内部按比例缩放，容易算错，先少用

五、今天的作业

  1. 统一 box-sizing：在 docs/css/main.css 最上面加那三行 （*, *::before, *::after { box-sizing: border-box; }）。 加完刷新，页面应该几乎没变化——因为你现在的布局很简单。这是打地基，不是改外观。
  2. 把日志卡片做成真正的卡片：给 .post 加 
    .post {
  padding: 16px 20px;
  border: 1px solid #e5e5e5;
  border-radius: 8px;
  margin-bottom: 20px;
}
    刷新首页，三篇日志应该变成三张独立的卡片。
  3. 观察 margin 折叠：卡片之间的间距是 20px 还是 40px？ 用 DevTools 选中第二张卡片，看它上下两边的橙色区域，然后写一句你的观察。
  4. 复现一次溢出（重要）：在 DevTools 里给某个卡片临时加 padding: 60px，看它有没有撑出容器。 再把 box-sizing 从 border-box 改成 content-box，对比两次的结果。 这个实验做过一次，你就再也不会忘记 box-sizing 是干什么的。
  5. 读一次盒模型：选中导航里的一个链接，在 Styles 面板的盒模型图上读出 content / padding / border / margin 四个数值，写在 main.css 的注释里。

这五条做完，你的站点会出现第一层"卡片感"。下周学完 Flexbox 之后， 这些卡片会再变一次样子——那时候你才真正开始"设计"而不只是"排版"。
