第 24 天：数组与对象

前端 90% 的数据只有两种形状：一串东西（数组）和一个带字段的东西（对象）。

一、数组基础

const nums = [1, 2, 3, 4, 5];

nums[0]        // 1       下标从 0 开始
nums[4]        // 5
nums[5]        // undefined   越界不报错
nums.length    // 5

增删的四个方法

const arr = [1, 2, 3];

arr.push(4);        // 末尾加     → [1,2,3,4]      返回新长度
arr.pop();          // 末尾删     → [1,2,3]        返回被删的元素
arr.unshift(0);     // 开头加     → [0,1,2,3]      返回新长度
arr.shift();        // 开头删     → [1,2,3]        返回被删的元素
这四个都会改原数组（专业性说法叫"有副作用"）。

slice 和 splice：一个不改，一个改（重点）

方法改原数组吗返回什么记法
slice(开始, 结束)不改截出来的新数组slice = 切片，切一份新的
splice(开始, 个数)改被删掉的元素splice = 剪接，从原串里剪掉
 
const a = [1,2,3,4,5];
a.slice(1, 3);      // [2, 3]        a 还是 [1,2,3,4,5]
[2, 3] 原数组 [1, 2, 3, 4, 5]
const b = [1,2,3,4,5];
b.splice(1, 2);     // 返回 [2, 3]
[2, 3] 原数组 [1, 4, 5] ← b 被改了

注意 slice(1, 3) 的两个数字含义不同：开始下标和结束下标（不含 3）。 splice(1, 2) 是开始下标和删几个。名字只差一个字母，参数含义不同。

二、五个必会的高阶方法

这些方法的参数都是函数——就是昨天学的回调。它们是前端日常使用频率最高的 API。

1. forEach —— 遍历，只为副作用

const nums = [1, 2, 3, 4, 5];
nums.forEach(n => console.log(n));
1 2 3 4 5
forEach 的返回值永远是 undefined。实测确认。
所以 const r = arr.forEach(...) 拿到的永远是 undefined。 它只用于"对每个元素做点事"（打印、改 DOM），不用来产出新数据。

2. map —— 每个元素转换一次，得到新数组

const doubled = nums.map(n => n * 2);
doubled = [2, 4, 6, 8, 10] nums 还是 [1, 2, 3, 4, 5] ← 原数组没变

map 一定返回一个长度相同的新数组。数量不变，只变每个元素。
这个"不改原数组"的性质很重要——React/Vue 里都靠它做"不可变更新"。

3. filter —— 留下符合条件的，得到新数组

nums.filter(n => n > 3);
[4, 5] ← 长度可能变短

回调函数返回 true 的元素保留，返回 false 的丢掉。不修改原数组。

4. find —— 找到第一个符合条件的元素

nums.find(n => n > 3);      // 4      ← 返回元素本身，不是数组
nums.find(n => n > 99);     // undefined   ← 找不到返回 undefined
方法返回找不到时
filter数组（可能空）[]
find一个元素undefined

5. reduce —— 把一堆值压缩成一个

// 求和
nums.reduce((sum, n) => sum + n, 0);        // 15

// 找最大值
nums.reduce((max, n) => (n > max ? n : max));   // 5

两个参数要分清：

nums.reduce((累加器, 当前元素) => 新的累加器, 初始值)
轮次累加器当前元素返回值
第 1 轮0（初始值）11
第 2 轮123
第 3 轮336
…………
最后10515
忘了给初始值会怎样： 
[].reduce((a, b) => a + b)     // TypeError: Reduce of empty array with no initial value
[].reduce((a, b) => a + b, 0)  // 0   ← 有初始值就安全
习惯上永远给初始值，尤其是处理可能为空的数组时。

补充：some 和 every

nums.some(n => n > 4);      // true    有一个满足就行
nums.every(n => n > 4);     // false   全都要满足

三、对象

const user = {
  name: "熙熙",
  age: 22,
  skills: ["HTML", "CSS"],
};

user.name           // "熙熙"     点号
user["name"]        // "熙熙"     方括号，字符串
user.skills[0]      // "HTML"     对象里套数组
user.city           // undefined  ← 不存在的属性不报错

点号 vs 方括号：什么时候必须用方括号

const key = "name";

user.name       // "熙熙"
user[key]       // "熙熙"     ← 方括号里可以放变量
user.key        // undefined  ← 点号后面是"字面量名字"，不是变量
点号后面永远是一个固定的属性名，不会被当成变量。
user.key 找的是"名为 key 的属性"（不存在），而不是"key 变量里存的那个名字"。 要动态取属性，必须用方括号。

实际用途：遍历对象时、或者属性名来自用户输入/接口返回时，都只能用方括号： obj[someVariable]。

取所有键、值、键值对

Object.keys(user)      // ["name", "age", "skills"]
Object.values(user)    // ["熙熙", 22, ["HTML","CSS"]]
Object.entries(user)   // [["name","熙熙"], ["age",22], ...]

判断对象是否为空：Object.keys(obj).length === 0。 不能写 if (obj)——空对象是真值。

四、解构：一次取出好几个

对象解构

const user = { name: "熙熙", age: 22 };

const { name, age } = user;
console.log(name, age);
熙熙 22

重命名（属性名和新变量名不同时）：

const { name: userName } = user;
console.log(userName);      // "熙熙"
// 冒号后面是新变量名，user.name 本身没变

默认值（属性可能不存在时）：

const { city = "佛山" } = user;
console.log(city);          // "佛山"

数组解构

const nums = [1, 2, 3, 4, 5];

const [first, second] = nums;        // 1 2
const [a, , c] = nums;               // 1 3   ← 逗号跳过第二个
const [x, ...rest] = nums;           // x=1, rest=[2,3,4,5]
数组解构按位置对应，对象解构按名字对应。这是两者最大的区别。
所以数组解构里的顺序很重要，对象解构里的顺序无所谓。

五、展开运算符 ...

把数组或对象"摊开"。

数组

const a = [1, 2];
const b = [3, 4];

[...a, ...b]        // [1, 2, 3, 4]      合并
[...a, 0]           // [1, 2, 0]         加元素
const copy = [...a];  // 浅拷贝，改 copy 不影响 a

对象

const user = { name: "熙熙", age: 22 };
const updated = { ...user, city: "佛山" };
// { name: "熙熙", age: 22, city: "佛山" }

const overridden = { ...user, age: 23 };   // 后面的覆盖前面的
// { name: "熙熙", age: 23 }

顺序决定谁覆盖谁：展开在前，后面的字段覆盖它；展开在后，前面的字段被它覆盖。

展开是"浅拷贝"——只复制第一层。
如果对象里有嵌套对象或数组，复制后两边还是指向同一个内层对象，改一个另一个也变。 深拷贝要用 structuredClone(obj)（现代浏览器和 node 都支持）。

六、三个常见错误

① 以为 forEach 能产出新数组

const result = nums.forEach(n => n * 2);
console.log(result);      // undefined
不报错，拿到 undefined，后面 .map() 会报 not a function

② sort 会改原数组（而且默认按字符串排）

const c = [3, 1, 2];
const sorted = c.sort();
console.log(sorted);    // [1, 2, 3]
console.log(c);         // [1, 2, 3]   ← c 也被改了
[1, 2, 3] 原数组 c = [1, 2, 3] ← 被改了
想排序又不想改原数组：[...arr].sort()。
另外默认的 sort() 把元素当字符串比，[10, 9, 1].sort() 会得到 [1, 10, 9]。数字排序要写 sort((a, b) => a - b)。

③ 对象解构时用了不存在的属性名

const user = { name: "熙熙" };
const { userName } = user;
console.log(userName);    // undefined
不报错，拿到 undefined

七、练习（10 题）

写在 02-javascript/practice/day24.js，用 node 运行。

const products = [
  { name: "键盘", price: 299, category: "电子" },
  { name: "鼠标", price: 89, category: "电子" },
  { name: "笔记本", price: 15, category: "文具" },
  { name: "显示器", price: 899, category: "电子" },
  { name: "钢笔", price: 45, category: "文具" },
];
  1. 用 map 取出所有商品的名字，得到 ["键盘","鼠标","笔记本","显示器","钢笔"]
  2. 用 filter 取出所有「电子」类商品
  3. 用 filter 取出价格大于 100 的商品，再用 map 只取名字
  4. 用 find 找出第一个价格超过 500 的商品
  5. 用 reduce 算出所有商品的总价
  6. 用 reduce 算出最贵的商品（返回整个对象）
  7. 用 some 判断有没有超过 800 的商品；用 every 判断是不是都小于 1000
  8. 对每个商品用 forEach 打印 "键盘 - ¥299" 这种格式
  9. 解构：从第一个商品里一次取出 name 和 price，然后打印
  10. 挑战：用 filter + map + reduce 一行算出「电子类商品的总价」
每题都要 console.log 出结果。第 3、10 题是链式调用—— 前一方法的返回值直接接下一个方法，这是前端最常用的写法。
