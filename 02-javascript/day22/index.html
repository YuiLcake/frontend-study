昨天你只会"算"，今天开始代码会"判断"和"重复"。

一、先补昨天的四个点

三分钟过一遍，确认没有半懂的。

1. `console.log` 的三种形态

console.log           // 回显函数本身，不打印
console.log("你好")    // 调用（括号），打印
console.log = "你好"   // 赋值（等号），函数被替换，从此失效

2. 浮点数比较

0.1 + 0.2 === 0.3                        // false
Math.abs(0.1 + 0.2 - 0.3) < 1e-10        // true
// Math.abs 取绝对值，1e-10 = 0.0000000001（容忍度）

3. 变量必须声明

const name = "熙熙";   ✓
name = "熙熙";         ✗ 不报错，但创建了隐式全局变量（还会覆盖 window.name）

4. 反引号可以跨行

const t = `第一行
第二行`;                ✓ 反引号里换行原样保留
const b = "第一行
第二行";                ✗ SyntaxError

二、先弄清"真假"：真值与假值

if 的括号里放任何东西都行，JS 会先把它"转成真假"再决定走不走。 哪些算假，必须背下来——一共只有 6 个（加上 0 的两种变体算 8 个写法）：

假值（falsy）说明
false假本身
0数字零
0n大整数零（少用）
""空字符串（注意：里面有空格就不是空）
null空
undefined未定义
NaN不是数字的数字

除了这 6 个，其他全是真值。包括这几个反直觉的：

"0"        // 真值！非空字符串
" "        // 真值！空格也是字符
"false"    // 真值！非空字符串
[]         // 真值！空数组
{}         // 真值！空对象
最容易错的两个：[] 和 {} 是真值。
直觉上"空的"应该是假，但 JS 只看类型：数组和对象是"存在的实体"，所以为真。
判断数组是否为空要用 arr.length === 0，判断对象要用 Object.keys(obj).length === 0。

三、if / else if / else

① 正确写法

const age = 20;

if (age >= 18) {
  console.log("成年");
} else {
  console.log("未成年");
}

// 多分支
const score = 85;
if (score >= 90) {
  console.log("优秀");
} else if (score >= 75) {
  console.log("良好");
} else if (score >= 60) {
  console.log("及格");
} else {
  console.log("不及格");
}

else if 是从上往下依次判断，命中一个就跳出，后面的不再看。 所以顺序很重要：把范围大的放上面会吃掉小的。

② 常见错误

错误 A：漏括号

if age >= 18 {
  console.log("成年");
}
SyntaxError: Unexpected identifier 'age'

错误 B：把 === 写成 =（最危险）

if (age = 18) {
  console.log("永远会执行");
}
这行不报错，但逻辑全错。
age = 18 是赋值：先把 18 赋给 age，然后判断"18 是不是真值"——18 是真值， 所以这个 if 永远成立。
怎么发现：这种 bug 不会报错，只能靠读代码。写条件时养成习惯——只写三个等号。

错误 C：条件后面多写了分号

if (age >= 18); {
  console.log("不管条件真假都执行");
}
分号让 if 变成了"如果成立，就执行一个空语句"。后面的 {} 变成了独立的代码块，无条件执行。不报错，行为完全错。

错误 D：用字符串做大小比较

if (age >= "18") { }     // 能跑，但把 age 先转成字符串再比
if ("9" > "18") { }      // true ← 字符串逐位比，"9" 比 "1" 大
不报错，结果是错的

四、三元运算符：二选一的简写

① 正确写法

const age = 20;
const label = age >= 18 ? "成年" : "未成年";
//                        ↑条件   ↑真        ↑假

console.log(label);   // "成年"
场景用哪个
二选一，结果是一个值三元 a ? b : c
要执行多条语句if / else
超过两层嵌套别用三元，可读性会崩

② 常见错误

// 错误 A：漏冒号
const x = age >= 18 ? "成年";        // SyntaxError: Unexpected token ';'

// 错误 B：嵌套三层，谁都读不懂
const y = a > 1 ? "大" : a > 0 ? "中" : "小";   // 语法对，但别这样写

// 错误 C：把三元的返回值丢掉，拿来做分支语句
age >= 18 ? console.log("成年") : console.log("未成年");   // 能跑，但不如 if 清楚

五、switch：多个固定值分支

① 正确写法

const role = "admin";

switch (role) {
  case "admin":
    console.log("管理员");
    break;                  // ← 必须写
  case "student":
    console.log("学生");
    break;
  default:
    console.log("未知角色");
}

② 常见错误：漏了 break

switch (role) {
  case "admin":
    console.log("管理员");
    // ← 没有 break
  case "student":
    console.log("学生");
    break;
}
// 输出：管理员
//       学生      ← 不应该出现的第二行
这叫 fallthrough（穿透）：没有 break 就会继续执行下一个 case 的代码。
不报错，只是多打印了一行。每个 case 结尾都要有 break（最后一个和 default 除外）。

什么时候用 switch，什么时候用 if：判断"是不是这几个固定值之一"用 switch； 判断"是不是在某个范围"用 if。switch 用的是全等比较 ===， 所以 case "1" 不会匹配数字 1。

六、for 循环

① 正确写法

// 经典 for：三段式
for (let i = 0; i < 5; i++) {
  console.log(i);        // 0 1 2 3 4
}

// 遍历数组
const skills = ["HTML", "CSS", "JS"];
for (let i = 0; i < skills.length; i++) {
  console.log(skills[i]);
}

// 更简单的写法：for...of（只取值，不需要下标时用）
for (const skill of skills) {
  console.log(skill);
}

三段式的三个部分：初始化（let i = 0）→ 条件（i < 5） → 每轮结束后的动作（i++）。

② 常见错误

错误 A：忘了 i++（死循环）

for (let i = 0; i < 5;) {
  console.log(i);        // 0 0 0 0 0 ... 永远不停
}
不报错，浏览器卡死（页面无响应，只能关标签页）

错误 B：边界写错（off-by-one）

const arr = [1, 2, 3];
for (let i = 0; i <= arr.length; i++) {
  console.log(arr[i]);   // 1 2 3 undefined
}                        //                    ↑ 多跑了一次，下标 3 不存在
数组下标从 0 开始，长度是 3 的数组，合法下标是 0、1、2。 <= 会跑到 3，拿到 undefined。一律用 <。

错误 C：在循环里改数组长度

const list = [1, 2, 3, 4];
for (let i = 0; i < list.length; i++) {
  list.pop();            // 边遍历边删，结果不可预测
}
不报错，结果和你想的不一样

七、while 与 break / continue

① 正确写法

// while：条件成立就一直做，适合"不知道要循环几次"的场景
let count = 0;
while (count < 3) {
  console.log(count);
  count++;               // ← 一定要有让条件终将变假的动作
}

// break：立刻跳出整个循环
for (let i = 1; i <= 10; i++) {
  if (i === 3) break;
  console.log(i);        // 1 2
}

// continue：跳过这一轮，继续下一轮
for (let i = 1; i <= 5; i++) {
  if (i === 3) continue;
  console.log(i);        // 1 2 4 5
}

② 常见错误

// 错误：忘了 count++，死循环
let n = 0;
while (n < 3) {
  console.log(n);        // 0 0 0 ... 卡死
}

// 错误：break 与 continue 用反
for (let i = 1; i <= 5; i++) {
  if (i === 3) continue; // 想"到此为止"，结果只是跳过 3
}
