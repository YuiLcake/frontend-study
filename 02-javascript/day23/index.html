第 23 天：函数

把一段逻辑打包，起个名字，需要用的时候叫它。

一、为什么需要函数

假设你要算三次不同商品的总价，昨天你只能这样写：

// 第一件：单价 30，数量 2，税率 0.1
const total1 = 30 * 2 * (1 + 0.1);
console.log(`总价：${total1}`);

// 第二件：单价 15，数量 4
const total2 = 15 * 4 * (1 + 0.1);
console.log(`总价：${total2}`);

// 第三件：单价 99，数量 1
const total3 = 99 * 1 * (1 + 0.1);
console.log(`总价：${total3}`);

问题很明显：同样的算式抄了三遍。哪天税率从 0.1 改成 0.13， 你得改三处，漏一处就错。

用函数写：

function calcTotal(price, count) {
  const TAX = 0.1;
  return price * count * (1 + TAX);
}

console.log(calcTotal(30, 2));    // 66
console.log(calcTotal(15, 4));    // 66
console.log(calcTotal(99, 1));    // 108.9

三个好处：

  • 改一处全变——税率只写在一个地方
  • 能复用——以后别的地方也要算总价，一行调用就行
  • 名字即文档——calcTotal(30, 2) 一眼看懂在干什么，比 30 * 2 * (1 + 0.1) 清楚

二、三种写法

① 函数声明（最常用）

function greet(name) {
  return `你好，${name}`;
}

greet("熙熙");     // "你好，熙熙"

② 函数表达式（把函数赋给变量）

const greet = function (name) {
  return `你好，${name}`;
};

③ 箭头函数（2015 年新增，写起来最短）

const greet = (name) => {
  return `你好，${name}`;
};

// 只有一个参数时括号可以省
// 函数体只有一句 return 时，花括号和 return 都可以省（隐式返回）
const greet2 = name => `你好，${name}`;
写法特点什么时候用
function name() {}会"提升"，可以先调用后声明通用场景，最清楚
const name = function () {}不会提升，必须先定义后调用想强调"这是一个值"
const name = () => {}最短，但 this 行为和上面不同回调、数组方法里大量使用
今天先用函数声明。箭头函数先认识语法，等你写 map、filter、 事件回调时会天天用它——那时候再深入 this 的差别。

三、参数与返回值（重点）

① 正确写法

function add(a, b) {        // a、b 是形参（占位）
  return a + b;             // return 把结果交给调用者
}

const result = add(1, 2);   // 1、2 是实参（真值）
console.log(result);        // 3

没有 return 会怎样——这是今天最重要的坑： 

function add(a, b) {
  console.log(a + b);       // 打印了，但没有 return
}

const r = add(1, 2);
console.log(r);             // undefined ← 拿不到结果
console.log 和 return 是两件完全不同的事。
console.log 是"打印给人看"，return 是"把结果交给调用它的代码"。
函数没写 return，默认返回 undefined。

② return 的第二个作用：立刻结束函数

function check(age) {
  if (age < 18) {
    return "未成年";      // 执行到这里，函数立刻结束
  }
  return "成年";          // 上一行返回了就不会走到这里
}

console.log(check(15));   // "未成年"
console.log(check(20));   // "成年"
return 后面的代码不会执行。 
function f() {
  return 1;
  console.log("这行永远不会打印");
}
不报错，只是静默不执行。编辑器的灰色提示会告诉你"这行不可达"。

③ 默认参数

function greet(name = "同学") {
  return `你好，${name}`;
}

greet();           // "你好，同学"   ← 没传参就用默认值
greet("熙熙");      // "你好，熙熙"

没传参数时，形参的值是 undefined，不是 0 也不是空字符串。 所以 function add(a, b) { return a + b } 调用 add(1) 会得到 NaN（1 + undefined）。

四、作用域：函数内部是"另一个房间"

const globalVar = "外面";

function test() {
  const localVar = "里面";
  console.log(globalVar);   // ✓ 能读到外面的
  console.log(localVar);    // ✓ 自己的
}

test();
console.log(localVar);      // ✗ 读不到
ReferenceError: localVar is not defined

规则：里面的能看到外面的，外面的看不到里面的。

位置能访问
函数内部自己的局部变量 + 外层变量
函数外部只有外层的，看不到函数内部的
为什么这样设计：每个函数是一个独立的房间，里面的东西不会漏到外面去污染别人。 这和昨天 for 循环漏写 let 是同一个道理——不声明就会漏，声明了才关在房间里。

五、函数是"值"，可以传来传去

这一点先认识一下，明天之后会天天用：

// 函数可以赋给另一个变量
function sayHi() {
  console.log("你好");
}
const fn = sayHi;      // 注意：没有括号，传的是函数本身
fn();                  // "你好"

// 函数可以作为参数传给另一个函数
function runTwice(callback) {
  callback();
  callback();
}
runTwice(sayHi);       // 打印两次"你好"
sayHi 和 sayHi() 是两回事。
sayHi 是函数本身（一个值）；sayHi() 是"现在执行它，把结果交给我"。
传给别人的时候通常要传函数本身（不加括号），否则传的是执行后的返回值。

这就是"回调函数"（callback）——你把一个函数交给别人，别人在合适的时机替你调用。 setTimeout、按钮点击、map、filter 全是这个模式。

六、五个常见错误

① 忘写 return

function double(n) {
  n * 2;                  // 算出来了，但没交出去
}
console.log(double(5));   // undefined
不报错，返回 undefined

② 用 console.log 代替 return

function double(n) {
  console.log(n * 2);     // 屏幕上看到 10，但函数返回 undefined
}
const x = double(5);      // x 是 undefined
console.log(x + 1);       // NaN
不报错，后续计算出 NaN

③ 定义完忘了调用

function greet() {
  console.log("你好");
}
// 只定义不调用，屏幕上什么都没有
不报错，什么都不发生

④ 箭头函数的隐式返回写错

// 正确：没有花括号 = 隐式返回
const double = n => n * 2;
double(5);        // 10

// 错误：加了花括号却没有 return
const bad = n => { n * 2 };
bad(5);           // undefined
不报错，返回 undefined

⑤ 参数顺序搞混

function divide(a, b) { return a / b; }
divide(10, 2);    // 5
divide(2, 10);    // 0.2   ← 顺序反了，结果不同但不报错
不报错，结果不对

写在 02-javascript/practice/day23.js，用 node 02-javascript/practice/day23.js 运行。

  3. 写 greet(name = "同学")，返回 "你好，xxx"，然后分别用传参和不传参调用一次
  4. 写 max(a, b)，返回较大的那个（不用 Math.max）
  5. 写 sumTo(n)，返回 1 到 n 的和（用循环）
  6. 写 repeat(str, times)，返回重复 times 次的字符串（不用 String.repeat）
  7. 写 countEven(arr)，返回数组里偶数的个数
  8. 用箭头函数写 square(n)，返回平方（用隐式返回，不写花括号）
  9. 找 bug：下面这段为什么打印 undefined？ 
    function area(w, h) {
  const result = w * h;
}
console.log(area(3, 4));
  10. 挑战：写 formatPrice(amount)，返回带两位小数的字符串，如 formatPrice(12.5) → "¥12.50"
每题都要真的调用一次并打印结果，不要只写函数定义。 函数写对了但没调用，屏幕上什么都没有——你也不知道对不对。
