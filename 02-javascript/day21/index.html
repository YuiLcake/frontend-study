第 21 天：JavaScript 入门

变量、类型、运算符。今天的内容不难，但要建立一种新的思维方式。

一、先换一种脑子

前四周你写的 CSS 是这样的：

.card { background: white; border-radius: 8px; }

这是描述——"卡片长这样"。你告诉浏览器结果，它自己想办法做到。 这叫声明式（declarative）。

JS 是这样的：

let total = 0;
for (let i = 1; i <= 10; i++) {
  total = total + i;
}
console.log(total);   // 55

这是指令——"先设成 0，然后从 1 数到 10，每次加起来"。 你告诉浏览器步骤，它照着执行。这叫命令式（imperative）。

这是接下来两周最大的思维转变。
CSS 写错了是"没效果"，JS 写错了是"算出错的结果"或者"直接报错"。 JS 会给你明确的错误信息——这是好事，比 CSS 的静默失败好排查得多。

二、JS 在哪运行

三种地方，今天主要用第三种：

方式写法适合
内联脚本 <script>...代码...</script> 写进页面的功能
外部文件 <script src="app.js"></script> 正式项目（分离、可复用、可缓存）
控制台 F12 → Console → 直接敲 今天和以后每天练习用

控制台是第一教室

F12 → Console 面板 → 光标在闪烁 → 输入 → Enter。 

1 + 1
// 输出：2

"你好" + "世界"
// 输出：'你好世界'

console.log("这行会打印出来")
// 输出：这行会打印出来

控制台的好处是"即时"：改一个字符，回车，立刻看到结果。 不用保存、不用刷新、不用建文件。学语法阶段全在控制台里做，效率最高。

一个必须知道的区别：
在控制台输入 "你好" 会直接回显 '你好'；
在 .js 文件里写 "你好" 什么都不会发生——文件里必须用 console.log 主动打印。
控制台是"回声"，文件是"哑巴"。

三、变量：给值起个名字

let age = 22;
const name = "熙熙";

age = 23;        // ✓ 可以改
name = "小明";    // ✗ 报错：Assignment to constant variable

let 还是 const

关键字能不能重新赋值什么时候用
const不能默认用它，大部分变量定下来就不该变
let能确实需要改的时候（计数器、累加）
var能不要用，见下面
为什么不用 var：
var 是 2015 年之前的唯一选择，有两个历史遗留问题：
① 它会"提升"到函数顶部，在声明之前就能访问，值是 undefined；
② 它不受代码块 {} 限制，if 里声明的变量会漏到外面。
现在所有教程都推荐 let / const。看到老代码里的 var，知道是什么就行。

命名规则

✅ userName      小驼峰，两个单词首字母大写
✅ maxCount
✅ isLogin       布尔值习惯加 is / has 前缀

❌ user-name     连字符（会当成减法）
❌ 2name         数字开头
❌ user name     空格
❌ 用户名         中文能跑，但别用

命名是给人看的。三个月后你会感谢自己写的是 totalPrice 而不是 a。

四、六种基础类型

类型例子说明
string 字符串"你好"、'abc'、`模板`文本，单双引号都行
number 数字42、3.14、-7整数小数都是它，不区分
boolean 布尔true、false只有两个值
undefinedlet x;声明了但没赋值
nulllet x = null;主动表示"空的"
object 对象{}、[]、函数后面专门讲

用 typeof 检查

typeof "你好"      // "string"
typeof 42          // "number"
typeof true        // "boolean"
typeof undefined   // "undefined"
typeof null        // "object"    ← 这是个 bug，别纠结
typeof {}          // "object"
typeof null === "object" 是 JS 最著名的历史遗留 bug。
1995 年实现时类型标记的二进制位写错了，改的话会破坏全世界的网页，所以将错就错到今天。 判断 null 要用 x === null，不要用 typeof。

JS 是动态类型

let x = 42;        // 现在是数字
x = "你好";         // 变成字符串，不报错
x = true;          // 又变成布尔

变量本身没有类型，值才有。同一个变量可以装不同东西——这叫动态类型。 灵活，但也容易写出意料之外的 bug（后面 TypeScript 就是来治这个的）。

五、运算符

算术

7 + 3      // 10
7 - 3      // 4
7 * 3      // 21
7 / 3      // 2.3333333333333335
7 % 3      // 1     ← 取余数
2 ** 10    // 1024  ← 幂
小心浮点数：0.1 + 0.2 不等于 0.3
0.1 + 0.2          // 0.30000000000000004
0.1 + 0.2 === 0.3  // false
所有编程语言都这样（二进制存不下 0.1）。比较小数要用 Math.abs(a - b) < 1e-10。

比较：== 和 === 的区别（重点）

1 == "1"      // true    ← 只比值，会自动转类型
1 === "1"     // false   ← 比值也比类型
写法叫什么做什么用不用
==相等（宽松）先把两边转成同一类型再比不用
===全等（严格）类型不同直接 false只用这个
== 的转换规则几乎没法记： 
0 == ""          // true
0 == "0"         // true
"" == "0"        // false     ← 上面两个都 true，这个却 false
null == undefined  // true
null === undefined // false
结论：永远用 === 和 !==。少一个等号，多一个无法预测的 bug。

逻辑与字符串

true && false     // false   两个都真才真
true || false     // true    有一个真就真
!true             // false   取反

"你好" + "世界"     // "你好世界"   加号在字符串上是拼接
"总数：" + 42      // "总数：42"   数字自动转字符串
+ 是双重身份：两边都是数字就相加，只要有一边是字符串就拼接。
1 + 2 + "3" → "33"（先算 1+2=3，再和 "3" 拼成 "33"）
"1" + 2 + 3 → "123"（先拼 "12"，再拼 "123"）

六、模板字符串

要拼接变量时，别用加号：

const name = "熙熙";
const age = 22;

// 旧写法：加号 + 手动空格
"我是" + name + "，今年" + age + "岁"

// 新写法：反引号 + ${}
`我是${name}，今年${age}岁`

三个好处：

  1. 不用管空格和引号嵌套
  2. 可以换行（普通引号不行）
  3. ${} 里可以放表达式：`明年${age + 1}岁`

反引号在哪：键盘左上角 Esc 下面那个键，和 ~ 同一个。 英文输入法下按它。中文输入法下容易打成全角字符，会导致语法错误。

七、练习：12 道控制台小题

全部在 Console 里做。先自己在脑子里猜答案，再回车验证—— 猜错的那道就是你需要弄懂的地方。

变量与类型

  1. 声明一个 const 常量存你的名字，然后用 console.log 打印它
  2. 声明一个 let 存年龄，改大 1 岁，再打印
  3. 试试给上面的 const 重新赋值，看报什么错，把错误信息读一遍
  4. 分别用 typeof 检查：42、"42"、true、null、undefined

运算符

  1. 计算 17 % 5 和 2 ** 8，说出结果
  2. 先猜再验证：1 == "1"、1 === "1"、0 == ""、null == undefined
  3. 先猜再验证：1 + 2 + "3" 和 "1" + 2 + 3 分别是什么
  4. 0.1 + 0.2 是多少？和 0.3 相等吗？

模板字符串

  1. 声明 name 和 city（佛山），用模板字符串输出「我是熙熙，来自佛山」
  2. 用模板字符串算出「明年我 23 岁」（年龄用变量，${age + 1}）
  3. 用模板字符串写一个三行的内容（含换行），打印出来
  4. 挑战：不用 if，只用一个模板字符串和运算符，输出「10 除以 3 等于 3，余 1」
做完之前别翻资料。答不出来就写"这道不会"——不会的题比猜对的题有用， 它告诉我们要补哪里。
