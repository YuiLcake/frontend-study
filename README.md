## 怎么跑起来

没有构建步骤，纯 HTML。用本地服务器打开（不要双击文件，file:// 协议下
ES Module 和 fetch 会被浏览器拦掉）：

```bash
cd 01-html-css/day1
python -m http.server 8123
# 浏览器访问 http://localhost:8123/
```
